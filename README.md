# ClimaGest — Protótipo

Protótipo navegável de ERP para empresas de instalação e manutenção de ar-condicionado.

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório público chamado `climagest`.
2. Envie os arquivos `index.html`, `styles.css`, `app.js` e `README.md` para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será semelhante a `https://SEU-USUARIO.github.io/climagest/`.

## Sobre o protótipo
- HTML, CSS e JavaScript puro.
- Layout responsivo para desktop e celular.
- Navegação entre módulos.
- Cadastros demonstrativos de clientes, equipamentos, orçamentos, ordens de serviço e estoque.
- Dados de demonstração persistidos no navegador com `localStorage`.
- Não possui backend, autenticação real, banco de dados compartilhado ou integrações reais.

Os dados e indicadores são fictícios, destinados à apresentação visual do conceito.
